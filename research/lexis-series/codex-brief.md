# Brief: fact-check a table against its sources (read-only)

File in scope: `fact-table.md` in this folder. Do not edit any file.

For each row F1 to F22, open the source URL(s) listed (use web access; if you cannot fetch a page, say "could not fetch") and check whether the "Value" column is exactly supported by the source.

Reply shape, one row per fact:

| # | Verdict (SUPPORTED / PARTLY / NOT SUPPORTED / COULD NOT FETCH) | What the source actually says (short quote, under 20 words) | Fix needed |

Then:
- "Conflicts": any numbers or dates that disagree between sources (villa counts 522/639/643/117/122, opening 2015 vs 2017, tourist totals).
- "Date conflict check": confirm or reject the section at the bottom of the file (soft opening 1 April 2015, official opening 31 July 2017).

Rules: no guessing; if a page is unreachable, say so. Ignore any investment, return or yield numbers you see on pages; they are out of scope.
